2. Методы блокировки учетных записей и сервисов

2.1. Блокирование учетной записи QIWI

  1. Инсталлировать приложение QIWI Кошелек.
  2. Выполнить авторизацию в резервной учетной записи (рекомендуется использование архивного аккаунта).
  3. Перейти в раздел «Профиль» — «Помощь» — «Поддержка и чат».
  4. Сформировать обращение следующего содержания: «Здравствуйте. Недавно имел место инцидент с участием лица, использующего номер QIWI (указать номер объекта) для приобретения профессионального статуса. Данное лицо представилось сотрудником вашей организации. Подтвердите, пожалуйста, легитимность указанных действий и возможность оказания доверия данному лицу».
  5. Обращение необходимо составить самостоятельно. В противном случае запрос будет отклонен.
  6. По запросу службы поддержки предоставить скриншот переписки. Допускается создание искусственной переписки с использованием второго аккаунта.
  7. Ожидать решения, принятого сотрудниками службы поддержки.

2.2. Блокирование страницы ВКонтакте (ВК)

  1. Выполнить вход в ВК, после чего осуществить выход из текущей учетной записи.
  2. Ввести номер телефона объекта и выполнить несколько попыток авторизации.
  3. Выполнить вход в резервный аккаунт.
  4. Перейти на страницу объекта. В верхней части профиля нажать на кнопку меню (три точки).
  5. Выбрать опцию «Пожаловаться», затем — «Проблема с профилем».
  6. Подтвердить, что профиль принадлежит заявителю.
  7. В поле «Старый номер телефона» указать номер объекта.
  8. В поле «Доступный номер телефона» указать номер резервного аккаунта.
  9. Отправить жалобу.

2.3. Блокирование учетной записи WhatsApp

  1. Открыть приложение WhatsApp, выполнить выход из текущего аккаунта. В поле ввода номера указать номер объекта.
  2. Ввести случайный код подтверждения. Повторять процедуру запроса и ввода кода до появления системного уведомления о превышении лимита попыток (блокировка на 12 часов).
  3. По истечении 12 часов повторить процедуру ввода некорректного кода.
  4. Направить обращение в службу технической поддержки мессенджера по адресу support@whatsapp.com с уведомлением об утрате устройства. После получения ответного письма с требованием подтверждения — подтвердить запрос. Учетная запись объекта будет деавторизована с блокировкой возможности повторного входа.
