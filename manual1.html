1.2. Методы поиска в социальных сетях

Осуществляется поверхностный поиск информации по социальным сетям (VK, OK, Facebook).

1.3. Алгоритм установления персональных данных (на примере VK)

Для получения сведений (ФИО, дата рождения, учебное заведение) применяется следующий порядок действий:

  1. Необходимо перейти на страницу объекта, открыть вкладку «Друзья» и скопировать цифровой идентификатор из адресной строки (параметр после «friends»).
  2. Примечание: метод неприменим к пользователям с идентификатором, начинающимся на 440 и выше.
  3. Следует ввести скопированный идентификатор с префиксом «id» в поисковые системы (Google, Яндекс). Анализ результатов позволяет получить дополнительные сведения (имя при регистрации, телефон, связанные группы). При отсутствии результатов осуществляется переход на страницу пользователя для определения даты рождения (в 87% случаев указывается день и месяц, год вычисляется аналитически). Далее открывается список друзей, выбирается город (возможно указание Москвы или Санкт-Петербурга). Проверяются первые три города после указанных. При числе друзей менее 10 используется сервис 220vk.com для выявления скрытых связей. Определяется преобладающий год рождения среди друзей (соответствует году рождения объекта). На платформе OK.RU выполняется поиск по имени и городу; при отсутствии результатов — по дате рождения (вероятность совпадения 100%). Устанавливаются фамилия и имя (в 50% случаев — отчество). При отсутствии данных об отце его возраст вычисляется путем прибавления 18 лет к возрасту объекта, после чего выполняется поиск.
  4. При сомнениях в принадлежности страницы конкретному лицу применяется метод сопоставления активности. Анализируется тип устройства (мобильный/ПК) и временные интервалы нахождения в сети. Например, при наличии двух профилей с идентичными данными, активных с мобильных устройств одновременно, и третьего, выходящего в сеть с интервалом в 3-5 часов, последний с высокой долей вероятности является искомым.

1.5. Поиск по базе данных «Одноклассники» (OK)

Применяются аналогичные методы, что и для VK.

Метод установления номера телефона через OK:

  1. Выполнить поиск по имени, городу и дате рождения.
  2. Выполнить поиск по инициалам и городу (с отсеиванием результатов).
  3. Использовать фильтр по городу и полной дате рождения.
  4. Осуществить поиск родственников по фамилии (с использованием вычисленного возраста).
  5. Проверить идентификатор канала YouTube в Google для установления предыдущих названий.

Инструкция по восстановлению доступа:

  1. Добавить профиль VK в друзья.
  2. Перейти в OK и открыть раздел «Друзья».
  3. Использовать функцию «Добавить друга из ВК».
  4. Скопировать ссылку на найденный профиль.
  5. Перейти по адресу https://ok.ru/password/recovery и выбрать восстановление через профиль.
  6. Вставить ссылку в поле поиска. Система отобразит часть номера телефона и адрес электронной почты.

Вспомогательный сервис: ok.city4me.com

1.8. Поиск по электронной почте и номеру телефона

Для поиска по электронной почте применяются операторы Google Dorks (целенаправленные поисковые запросы):

  • "@example.com" site:example.com — поиск почтовых ящиков на определенном домене.
  • HR "email" site:example.com filetype:csv | filetype:xls | filetype:xlsx — поиск контактов HR в форматах xls, xlsx, csv.
  • site:example.com intext:@gmail.com filetype:xls — извлечение ID почтовых ящиков Gmail из определенного домена.

Корректно сформированный поисковый запрос позволяет получить значительный объем данных.
